# Rohit M — Engineering Portfolio

A responsive, single-page engineering portfolio built with HTML, CSS and vanilla JavaScript. It is intentionally easy to run and edit without a build tool.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For local development, you can also use VS Code's Live Server extension.

## Customise
- Edit education, internship and project content in `index.html`.
- Edit project case-study details in `script.js`.
- Change colours, spacing and typography in `styles.css`.
- Replace the original concept illustrations with authentic project photos where available.
- Add your actual LinkedIn and GitHub links once confirmed.
- Add a resume PDF to this folder and then add a visible download link in the hero/contact sections if desired.

## Important accuracy notes
- The EV battery monitoring system is labelled as a proposed concept; prototype and testing are pending.
- The drone entry is labelled as details to verify. Confirm specifications, your exact contribution, and any funding claim before publishing.
- The website uses illustrative SVG/CSS concept art; it is not proof of physical prototypes.
- The portfolio is not affiliated with or endorsed by Ather Energy.

## Publish for free
### GitHub Pages
1. Create a GitHub repository (for example, `rohit-engineering-portfolio`).
2. Upload `index.html`, `styles.css`, `script.js`, and any local assets.
3. In repository Settings, open Pages.
4. Choose deployment from the `main` branch and root folder, then save.
5. Wait for the Pages build to finish and open the URL shown in Settings → Pages.
6. Test the live website on desktop and mobile before submitting it.
